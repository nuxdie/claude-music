# claude-music

**Purpose:** curiosity: can Claude actually compose music, from code, that's worth listening to?
**Outcome (2026-10, done):** yes. A week of experiments (hip-hop, rave, rock, jazz, "infernal engine", "paradise"),
then an EP and a C418-style album, *Volume Gamma*, published on YouTube (@artemops). The project is closed.

- `album/` — *Volume Gamma*, 12 tracks + bonus, C418-style, with pixel-art cover and videos (see album/README.md)
- `ep/` — *One Context*, a 6-track EP about a conversation's lifetime (see ep/README.md)
- `c418/`, `jazz/`, `*.py` at the top — the experiments that led there
- `synth.py`, `rig.py`, `album/kit.py` — the instrument and mixing toolkit

Renders, videos and the sample libraries aren't in git; see LIBS.md to rebuild.
