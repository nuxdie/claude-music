# Sample libraries and tools (not in git; fetch into libs/)
What `libs/` held when the album was made (2026-10). All free / open-licensed; re-download to re-render.
- salamander — Salamander Grand Piano (SFZ)
- vsco, vsco_linux — VSCO 2 Community Edition (orchestra)
- vpo — Virtual Playing Orchestra
- kw — KW upright bass
- drskit — DrumGizmo DRSKit
- surge — Surge XT (synth)
- sfizz-src — sfizz SFZ player (built from source)
- plugins — dragonfly-reverb 3.2.10
- nam — Neural Amp Modeler captures (guitar amps)
- standard_bass, standard_guitar — sample sets fetched with gdown
- voices — Piper TTS voice en_US-bryce-medium
- extra — jRhodes3c, Greg Sullivan E-Pianos, Ovation guitar, Karoryfer Emily, MTG Solo Sax, Cithara Barbarica lyre
Python deps: `python -m venv .venv && .venv/bin/pip install -r requirements.txt`
